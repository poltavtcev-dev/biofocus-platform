# 16. Ubiquitous Language & Glossary

- **Observation:** Исходный неизменяемый факт биометрии или контекста.
- **Life Event:** Пользовательский контекстный факт (Coffee / Walk / Lunch / Workout, …), моделируемый как `Observation` с `data_type: "life_event"` и `payload.kind` — не отдельная сущность БД (ADR-006).
- **Calendar Event:** Локальный календарный/meeting факт как `Observation` с `data_type: "calendar_event"` (uid/start/end/busy; без title/body) — dogfood через opt-in ICS (`BIOFOCUS_CALENDAR`), без cloud OAuth (P6-E3-T1).
- **Signal:** Зафиксированная в реальном времени аномалия или переход состояния (например, всплеск пульса).
- **Feature:** Рассчитанный за временной интервал метрический показатель (например, FocusScore), с `confidence` качества данных окна (ADR-007) и опциональными `factors` (P7-E2 — спокойный разбор вкладов входов) — не клиническая оценка.
- **Insight:** Готовый аналитический вывод с фактами-доказательствами (Evidence). Pattern Discovery v1 (ADR-008): baseline / multi-day Insights via recompute-on-read Feature series from Observations — not a persisted Feature history store; calm personal observation, not clinical diagnosis. Optional thin `actionRecommendation` text is a gentle hint only — not the L4 Recommendations contract (ADR-009).
- **Recommendation:** Детерминированное спокойное предложение действия (optional personal hint) с собственным Evidence (Feature / Signal / Insight ids). L4 (ADR-009): first-class type + `RecommendationRule` in `knowledge-engine`, evaluate-on-read, local-only; **not** clinical advice; **not** LLM-authored; **not** a persisted store in v1. Distinct from Insight (L3 Knowledge) and from L5 coaching interpret-only.
- **Prompt Pack (ADR-011 / P11-E2):** Named + versioned in-process template in `report-engine` (`build_report_with_pack`, default `biofocus.default` @ `1`) that formats already-computed Features / Insights / Recommendations into offline report markdown + interpret-only `llm_prompt`. Does **not** compute Features / Recommendations / Evidence; no SQLite pack store in v1.
- **Provider UX (ADR-011 / P11-E3):** Calm Dashboard surface for opt-in local LLM status (`get_local_llm_status`: `disabled` / `ready` / `error`) + pack-aware Report flow (`generate_report` → `build_report_with_pack`, default `biofocus.default` @ `1`) — explicit user action only; UI ↛ SQLite; default LLM off.
- **Provider / Plugin:** Источник данных (модуль), отправляющий `Observation`. Capability Plugin Model (`docs/08-plugin-sdk.md`): plugins declare Capabilities + `data_types`, stream via `start_stream` / `stop_stream` into the shared Observation channel — opt-in, idle-safe, no busy-loop.
- **Browser Category (Observation):** Coarse in-browser context label as `Observation` with `data_type: "browser_category"` (ADR-010 wave-1) — categories only (`work` / `communication` / …); **no** full URLs or page titles. Opt-in `BIOFOCUS_BROWSER_CATEGORIES`. Feeds `DistractionScore` (P10-E3). Personal self-tracking only.
- **DistractionScore (Feature):** Catalog Feature for calm context fragmentation from `browser_category` Observations (+ optional `ContextSwitchRate`) — Phase 10 E3 / ADR-010. Omit when only-`unknown` / empty; ADR-007 confidence; not a clinical diagnosis.
- **Now Playing (Observation, ADR-012 / P12-E2):** Coarse ambient media fact as `Observation` with `data_type: "now_playing"` — `media_kind` + `is_playing` only; **no** titles / lyrics / playlists / mic. Opt-in `BIOFOCUS_NOW_PLAYING`. Personal self-tracking only.
- **AmbientMediaShare (Feature, ADR-012 / P12-E3):** Catalog Feature — share of a window with active personal media (`now_playing`); calm ambient context, not clinical. Omit empty / only-`none` / only-`unknown`. Packaging runbook: `docs/18-packaging-runbook.md` (signed builds / notarization / update stance) — open Core math unchanged.
- **Git Activity (Observation, ADR-013 / P13-E2):** Coarse personal VCS cadence as `Observation` with `data_type: "git_activity"` — `activity_kind` + optional `event_count` only; **no** paths / remotes / diffs / branch names / commit messages. Opt-in `BIOFOCUS_GIT_ACTIVITY`. Personal self-tracking only.
- **Git watched roots (ADR-014 / P14-E2–E3):** User-chosen absolute directory roots in local config `~/.biofocus/git-watched-roots.toml` that the live Git probe may watch — configuration only; paths must **not** enter Observation payloads. Empty/missing → soft-fail idle. Optional `BIOFOCUS_GIT_WATCHED_ROOTS` when file absent (tests/CI). Menubar **Git folders** IPC edits the file (UI ↛ SQLite). **No** SQLite allowlist in v1.
- **GitActivityRate (Feature, ADR-013 / P13-E3):** Catalog Feature — sum of countable coarse git events (`commit`/`checkout`/`sync`/`other`) per 15m window; calm personal cadence, not productivity policing or workplace monitoring. Distinct from `DistractionScore`.
- **Ambient Light (Observation, ADR-015 / P16-E1):** Coarse ambient brightness fact as `Observation` with `data_type: "ambient_light"` — `light_kind` + optional bounded `level` (0–100) only; **no** camera frames / screen contents / precise geo / mic. Opt-in `BIOFOCUS_AMBIENT_LIGHT`. Collector shipped (P16-E1). Weather ambient deferred.
- **AmbientLightShare (Feature, ADR-015 / P16-E2 — shipped):** Catalog Feature — calm share of window samples in closed-set ambient light bands (`dark`/`dim`/`moderate`/`bright`); not clinical lighting advice. Distinct from `AmbientMediaShare` / `GitActivityRate`. Omit empty / only-`unknown`.
- **Wearable depth Observations (ADR-018 / Phase 17):** HealthKit-backed facts beyond HR/HRV — `step_count`, `active_energy`, `sleep_interval`; soft-optional `oxygen_saturation`. Existing `observations` store; personal self-tracking; no Mi Cloud. Companion emit + Features shipped (P17).
- **Chart range series (ADR-018 / P17-E3):** Dashboard picker `1h`/`8h`/`12h`/`1d`/`1w` → `get_feature_series` recompute-on-read from Observations (ADR-008); Snapshot UI shows **latest** Features; series lives on the chart. UI ↛ SQLite; no Feature-history table in v1.
- **Notification Event (Observation, ADR-019 / P18 · ADR-020 live):** Coarse interruption fact as `Observation` with `data_type: "notification_event"` — required `count` (≥1) + optional closed-set `category` / `interruption_level` / `app_kind`; **no** body / title / message / screenshots. Opt-in `BIOFOCUS_NOTIFICATION_EVENTS` (default off). Live OS mapping: usernoted NC SQLite allowlist (P19-E2). Personal self-tracking only.
- **NotificationPressure (Feature, ADR-019 / P18-E3 — shipped):** Catalog Feature — calm interruption intensity (0–100) from `notification_event` cadence (`sum(count)` → map with saturation 20/15m); omit empty; ADR-007 confidence. Not clinical / workplace surveillance. Phase 19 unlocks live inputs only (no formula rewrite).
- **Live NC OS mapping (ADR-020 / P19 — shipped):** Read-only **usernoted** Notification Center SQLite → ADR-019 payloads for `SystemNotificationEventProbe`; allowlisted columns only; soft-fail when unavailable / TCC denied. Dogfood runbook in `docs/12-development.md` § Notification events dogfood. Not content capture / Accessibility scrape / workplace monitoring.
- **CognitiveLoad (Feature, ADR-021 / P20-E2–E3 — shipped):** Catalog Feature — calm combined demand (0–100) from Feature-level **MeetingDensity + ContextSwitchRate + NotificationPressure** (15m / 1m); renormalize present inputs, omit when none; ADR-007 slots = 3; explanation factors `meeting` / `switches` / `notifications`. Dashboard chart calm label **Combined demand** when present. Not clinical cognitive overload / burnout / workplace surveillance. No new Observation family. Dogfood: `docs/12-development.md` § CognitiveLoad dogfood.
- **DeepWorkScore (Feature, ADR-022 / P21-E2–E3 — shipped):** Catalog Feature — calm sustained-focus intensity (0–100) from Feature-level **FocusScore (required) + ContextSwitchRate (optional)** (15m / 1m); omit without Focus; renormalize when CSR absent; idle dropped for v1; ADR-007 slots = 2; explanation factors `focus` / `stability`. Dashboard chart calm label **Sustained focus** when present. Not clinical flow state / burnout / ADHD / workplace surveillance. No new Observation family. Dogfood: `docs/12-development.md` § DeepWorkScore dogfood.
- **AttentionStability (Feature, ADR-023 / P22-E2–E3 — shipped):** Catalog Feature — calm focus stability (0–100) from Feature-level **FocusScore range (required) + ContextSwitchRate (optional)** (15m / 1m); omit without Focus; renormalize when CSR absent; **distinct from DeepWorkScore intensity**. ADR-007 slots = 2; explanation factors `focus_stability` / `switch_stability`. Dashboard chart calm label **Focus stability** when present. Framing: “focus stability in this window” — not ADHD / “you can’t focus” / burnout. Catalog: `docs/06-feature-catalog.md` §1.18. Dogfood: `docs/12-development.md` § AttentionStability dogfood.
- **Personal Context Layer (ADR-024 / P23-E1–E3 — shipped first slice + dogfood):** Phase 23 product layer — (**1**) reference bands **Variant B** (personal baseline primary; literature secondary — large library deferred); (**2**) opt-in **user-declared** health context in local `~/.biofocus/health-context.toml` → prompt packs / report (L5); (**3**) desk-away via **`DeskAwayPresence`**. Dashboard chart calm label **Away from desk** when present. Health declare = edit config file (no clinical UI). Does **not** invent disease from biometrics; Feature math does **not** branch on health labels. Dogfood: `docs/12-development.md` § DeskAwayPresence / health-context dogfood. Provider-agnostic Observation contracts.
- **DeskAwayPresence (Feature, ADR-024 / P23-E2–E3 — shipped):** Catalog Feature — calm away-from-desk / break-or-walk likelihood (0–100) from quiet keystrokes / `context_window` (+ optional `step_count`, `life_event` walk). Omit without positive away evidence (walk or steps ≥ 40). Framing: “away from desk in this window” — not workplace surveillance / GPS. Chart label **Away from desk**. `register_desk_away_v1` / `register_catalog_v1`. Catalog: `docs/06-feature-catalog.md` §1.19.
- **Health context (profile, ADR-024 / P23-E2–E3 — shipped):** Opt-in user-declared curated condition ids (`sleep_sensitive` / `migraine_prone` / `caffeine_sensitive`) + optional free-text note, local-only `~/.biofocus/health-context.toml`. Consumed by prompt packs / reports as “User-declared context”; never LLM-invented; no cloud health sync by default; no SQLite profile store. Declare by editing the file.
- **CircadianOffset (Feature, ADR-025 / P24-E2–E3 — shipped):** Catalog Feature — calm schedule alignment (0–100) from Observation-level **sleep timing** (`sleep_interval`) vs **work/activity timing** (`keystrokes` / `context_window`, optional steps / active energy / workout). Cadence 15m / 1m with **24h lookback**; omit unless both slots present; ADR-007 slots = 2; factors `sleep_timing` / `work_timing` (+ optional `activity_timing`). Framing: “schedule alignment in this window” — not chronotype / circadian-disorder / “night owl so you fail”. Distinct from SleepDebt (debt magnitude) and DeskAwayPresence (away-from-desk). Dashboard chart calm label **Schedule alignment** when present. `register_circadian_v1` / `register_catalog_v1`. No new Observation family. Catalog: `docs/06-feature-catalog.md` §1.20. Dogfood: `docs/12-development.md` § CircadianOffset dogfood.

- **Core Daemon:** Фоновый процесс на Rust, обрабатывающий пайплайн данных.
